Job Description

At SZORZO, we’re seeking passionate System Engineers to help us build scalable, secure, and high-performance AI-driven solutions.

  • Minimum years of experience – 7 years
  • Build and operate resilient connectors to external APIs (auth, mapping, retries, idempotency).
  • Stand up CI/CD pipelines: build → test → scan → deploy → rollback; environment promotion.
  • Define infra as code; provision compute/storage/network; manage secrets/keys and backups.
  • Implement observability (structured logs, metrics, traces) and actionable dashboards/alerts.
  • Reliability operations: SLOs/SLIs, run-books, disaster recovery, capacity & cost guardrails.
  • Lead performance and resilience testing (load, backoff/jitter tuning, DLQ & replay jobs).

Requirements

  • Scripting/automation (Bash/PowerShell/Python); containers and orchestration basics.
  • CI/CD mechanics; rollback strategies; artifact/version management.
  • Networking + API fundamentals: HTTP/TLS/DNS, rate limiting, webhooks, OAuth/OIDC.
  • Queues/events, dead-letter handling, outbox/ledger patterns for exactly-once effects.
  • Observability and incident response (alert tuning, MTTR reduction).

Nice-to-haves

  • Contract testing (Pact), performance tools (k6), SBOM/vulnerability scanning, least-privilege IAM.
